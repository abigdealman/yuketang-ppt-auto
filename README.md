# 雨课堂 PPT 自动阅读助手

一个 Tampermonkey 用户脚本，用于按顺序打开雨课堂学习内容中的 PPT 课件，并在每页从“未读”变为已读或学习进度增加后继续下一页。

## 功能

- 自动按列表顺序打开未完成 PPT。
- 支持雨课堂旧式弹窗课件页和新版内嵌 `/ppt` 课件页。
- 已完成内容会跳过。
- 有得分的线上测验、练习题、作业等非 PPT 活动会跳过。
- PPT 内题目页不会自动作答，只会按跳过处理，避免卡住。
- 每页会等待“未读”状态消失或学习进度增加后再继续，避免点太快导致仍然未读。
- “未读”长时间不转已读、返回学习内容卡住、学习内容主页面或列表加载卡住时，会在次数上限内自动刷新恢复。
- 返回课件时如果出现“还有页面未观看”的提示，会自动点击“继续观看”并恢复处理未读页。
- 详情页长时间未进入阅读器时，会自动刷新恢复。
- 内置运行锁和跨 iframe 状态同步，减少重复安装或多页面脚本实例互相抢控制。
- 悬浮控制面板支持拖动、收起为悬浮球、调整大小。

## 安装

1. 安装 Tampermonkey。
2. 打开下面的 Raw 地址安装脚本：

   `https://gh-proxy.com/https://raw.githubusercontent.com/abigdealman/yuketang-ppt-auto/main/yuketang-ppt-auto.user.js?v=0.2.20`

3. 打开雨课堂课程页面。
4. 点击右侧面板里的“开始”。

## 更新

脚本内置 `@updateURL` 和 `@downloadURL`。通过上面的 Raw 地址安装后，Tampermonkey 会按版本号检查更新。

脚本也会定期主动检查远端版本；发现更高 `@version` 时，会在页面右上角提示打开更新，并为代理链接追加临时参数以减少缓存拿到旧版的情况。浏览器和脚本管理器通常不允许用户脚本静默替用户安装新版，因此仍需要用户点一次更新确认。

如果同时安装了多个脚本管理器，或安装了多份同名脚本，请只保留一份启用。旧版本实例可能会和新版本互相抢控制。

## 使用建议

- 建议从课程的“学习内容”页开始运行。
- 如果已经在某个课件页，也可以直接点击“开始”，脚本会识别当前课件阅读器。
- 换课后如果页面状态异常，先刷新页面，再点击“开始”。
- 面板标题会显示当前脚本版本，排查问题时请先确认版本号。

## 注意

本脚本只做页面点击、阅读状态确认和卡住时的页面刷新恢复，不包含答题、绕过校验、账号凭据读取、网络请求拦截或数据上传。请遵守课程平台和课程要求使用。
