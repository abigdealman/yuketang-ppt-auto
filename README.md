# 雨课堂 PPT 自动阅读助手

一个 Tampermonkey 用户脚本，用于按顺序打开雨课堂学习内容中的 PPT 课件，并在每页从“未读”变为已读后继续下一页。

## 功能

- 自动按列表顺序打开未完成 PPT。
- 已完成内容会跳过。
- 有得分的线上测验、练习题、作业等非 PPT 活动会跳过。
- PPT 内题目页不会自动作答，只会按跳过处理，避免卡住。
- 每页会等待“未读”状态消失或学习进度增加后再继续。
- 悬浮控制面板支持拖动、收起为悬浮球、调整大小。

## 使用

1. 安装 Tampermonkey。
2. 新建脚本，粘贴 `yuketang-ppt-auto.user.js` 的内容。
3. 打开雨课堂课程的学习内容页面。
4. 点击右侧面板里的“开始”。

## 注意

本脚本只做页面点击和阅读状态确认，不包含答题、绕过校验、账号凭据读取、网络请求拦截或数据上传。请遵守课程平台和课程要求使用。
